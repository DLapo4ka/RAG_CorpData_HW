# Улучшения проекта

## Выбранные направления

### 1) Улучшение интерфейса Streamlit — отображение показателей пищевой ценности

**Зачем нужно моему кейсу:**
Основная ценность проекта — помощь пользователям с диетическими ограничениями. Отображение калорий, белков и жиров напрямую в ответе позволяет быстро оценить рецепт без дополнительных кликов. Это ключевая информация для ЗОЖ-энтузиастов и людей, следящих за питанием.

**Что изменилось:**
- В ответе теперь отображаются калории, белки и жиры для каждого найденного рецепта
- Если данные о калорийности, белках или жирах отсутствуют в исходном рецепте, на их месте выводится `н/д`

**Какие файлы менялись:**
- `app/generator.py` — добавлено форматирование ответа с выводом КБЖУ из метаданных

**Как проверить:**
- Запустить UI: `uv run streamlit run app/main.py`
- Задать запрос, например: `"high protein ice cream"`
- В ответе проверить наличие строки с калориями, белками и жирами (или `н/д` при отсутствии данных)

**Статус:** Реализовано

### 2) Улучшение интерфейса Streamlit — история запросов

**Зачем нужно моему кейсу:**
Пользователи часто возвращаются к предыдущим запросам, чтобы сравнить рецепты или повторить удачный поиск. Без истории приходится заново вводить вопрос. Добавление истории упрощает навигацию и экономит время.

**Что изменилось:**
- В боковой панели Streamlit отображаются последние 5 запросов пользователя
- При клике на сохранённый запрос он автоматически подставляется в поле ввода и выполняется поиск
- История хранится только в рамках текущей сессии (не сохраняется между перезапусками)

**Какие файлы менялись:**
- `app/main.py` — добавлено хранение истории в `st.session_state` и виджет для отображения

**Как проверить:**
- Запустить UI: `uv run streamlit run app/main.py`
- Задать несколько разных вопросов (например, "chicken recipe", "pasta without cheese")
- Убедиться, что в боковой панели появился список "Последние запросы" с этими вопросами
- Нажать на любой сохранённый запрос — он должен подставиться в поле ввода и выполнить поиск

**Статус:** Запланировано
