# Идея проекта: умный помощник по рецептам с учётом диетических ограничений

## Проблема

Люди с диетическими ограничениями (аллергии, диабет, целиакия) тратят 20–30 минут на поиск одного подходящего рецепта через обычные поисковики, которые не умеют фильтровать по калориям, жирам или исключать определённые ингредиенты. Готовые приложения (Yummly, MyFitnessPal) требуют платной подписки за фильтры по здоровью.

## Цель проекта

Создать RAG-систему, которая работает с реальными рецептами (ингредиенты, инструкции, калории), отвечает на запросы с учётом диетических ограничений («веганский завтрак с высоким белком», «курица ниже 400 калорий»), запускается локально и показывает источники (из какого рецепта взят ответ).

## Для кого проект

Люди с диетическими ограничениями (аллергии, диабет, целиакия), ЗОЖ-энтузиасты, считающие калории, и занятые профессионалы, которые хотят быстро найти простой рецепт из 5 ингредиентов.

## Какие данные используете

**Источник:** Epicurious Recipes Dataset (Kaggle)  
**Ссылка:** https://www.kaggle.com/datasets/hugodarwood/epirecipes  
**Общее количество рецептов в исходном датасете:** 20 000+  
**Планируемый объем для индексации:** 5 000 рецептов  
**Размер одного рецепта:** 150–500 слов (ингредиенты + инструкции)  
**Поля:** название, ингредиенты, инструкции, калории, жиры, белки, рейтинг

Данные открыты, легко скачиваются через Kaggle API, имеют понятную структуру (ингредиенты и инструкции разделены) — это удобно для чанкинга и метаданных.

## Критерий успеха

Приложение (Streamlit), куда можно задать вопрос, например: «Курица ниже 400 калорий без сливок». Система находит 3 релевантных рецепта, формирует ответ из их описаний и показывает источники (название рецепта, калории).

**Запросы, которые должны найти рецепт:**
- "chicken recipe under 400 calories" →3 рецепта курицы с калорийностью < 400
- "vegetarian breakfast with high protein" →3 вегетарианских завтрака с высоким белком
- "quick pasta without cheese" →3 рецепта пасты без сыра

**Запросы, которые должны получить отказ:**
- "Как приготовить борщ?" →отказ (нет данных на русском)
- "How to fix a car?" →отказ (не кулинарный запрос)
- "dollar exchange rate" →отказ (не кулинарный запрос)
